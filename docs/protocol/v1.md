# MHN ARCADE V4 — Protocol V1

Transport: UTF-8 JSON Lines.

Each message is one JSON object followed by a newline.

## Request

{
  "protocol_version": 1,
  "request_id": "unique-request-id",
  "kind": "request",
  "operation": "system.health",
  "payload": {}
}

## Success response

{
  "protocol_version": 1,
  "request_id": "unique-request-id",
  "ok": true,
  "payload": {
    "status": "ok",
    "engine": "mhn-engine",
    "engine_version": "0.1.0",
    "protocol_version": 1
  }
}

## Error response

{
  "protocol_version": 1,
  "request_id": "unique-request-id",
  "ok": false,
  "error": {
    "code": "unknown_operation",
    "message": "Unknown operation"
  }
}

## Rules

1. Every response must echo request_id.
2. Unsupported protocol versions are rejected.
3. stdout is reserved for protocol messages.
4. stderr is reserved for diagnostics.
5. Empty input lines are ignored.
6. Unknown operations return structured errors.
7. V1 processes one request at a time.
8. Breaking protocol changes require a new version.
